# Margadarshi: AI Route Map Generator for Students
A Flask app where a student enters 4 things (current education, interests, passion, skills) and
Google Gemini generates a personalized route map: career options, courses, exams and a flowchart.
No database; everything is generated by the LLM.

Free API key: https://aistudio.google.com/apikey

## Windows CMD
```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
set GEMINI_API_KEY=YOUR_API_KEY
python app.py
```
Open http://127.0.0.1:5000

Optional: `set GEMINI_MODEL=gemini-2.5-flash-lite` (higher free-tier limit).
Never commit your API key. Verify exams and dates on official websites.
